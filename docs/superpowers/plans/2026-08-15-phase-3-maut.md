# Phase 3 — MAUT Scorer & Continuous Arbitration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: test-driven-development. RED → GREEN → commit per task.

**Goal:** Replace the static priority-band + action-cascade sort with a continuous Multi-Attribute Utility score `U = Σ w_k·u_k` (workflow §13–23), wiring in Phase 2's `G_soft`, dynamic context weights, and an explanation trace — while every recommendation retains a deterministic `action`/`SessionIntent` so the tutor pipeline keeps working.

**Architecture:** New pure module `src/engine/maut.ts` (four sub-utilities, dynamic weights, composite aggregator, `intentForAction`). `recommend.ts` computes `U` per candidate, dedupes by target keeping max `U`, and sorts by `U` (tiebreak: curriculum index → title). Guards remain candidate generators; `priority`/`when`/`action` stay as metadata + drive `intent`.

**Tech stack:** TypeScript, Vitest. No new deps. Baseline: `fix/engine-workflow-remediation` after Phase 2 (`9a60e76`).

## Global Constraints

- Derive-don't-store; pure; named constants in `CONFIG.RECO`.
- All `u_k ∈ [0,1]`; weights non-negative pre-normalization, `Σ w = 1` after (workflow §47, §54.6).
- Deterministic for identical input.

## Resolved decisions (from user directive)

- **D5 — `u_feas` asymmetric:** `1.0` if `t_est ≤ T_rem`, else `exp(−(t_est−T_rem)²/(2σ²))`, `σ=FEASIBILITY_SIGMA=15`. `T_rem` unknown → `1.0`. Cognitive-load term descoped.
- **D6 — `domainId = section_id`** (Phase 4 interleaving; recorded now).
- **u_found:** `G_soft(n)·min(1, Σ_k Weight(v_k)(1−L(v_k)) / (dist(n,v_k)·max(1, t_exam(v_k)−t)))`. `Weight` default `1`; `t_exam` default horizon `30d` when none.
- **Weights:** base `{mem .35, found .30, vel .20, feas .15}`; exam-horizon (<7d) and exhaustion (<15min) shifts per directive; `max(0.01, w)` then L1-normalize.
- **Action-intent:** each rec keeps `action` (from its guard) + a derived `intent` via `intentForAction`.

  utility: number;
  subUtilities: { memoryUrgency: number; foundationalRisk: number; curriculumVelocity: number; sessionFeasibility: number };
  weights: MAUTWeights;
  dominantUtility: 'mem' | 'found' | 'vel' | 'feas';

export function memoryUrgency(topic: Topic, now?: Date): number;
export function foundationalRisk(topic: Topic, store: Store, now?: Date): number;

export function sessionFeasibility(estMinutes: number, timeRemaining: number | null): number;
export function deriveMAUTWeights(store: Store, ctx: MAUTContext, now?: Date): MAUTWeights;
export function compositeUtility(topic: Topic, estMinutes: number, store: Store, ctx: MAUTContext, now?: Date): UtilityBreakdown;
