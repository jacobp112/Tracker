## Colours

Ink `#1a1a1a` · Cream `#ffffeb` · Forest `#034f46` · Lavender `#f0d7ff` · Ember `#ffa946`

No other colours. The mark never appears in a colour outside the palette, and never gains a shadow or gradient.

## Type

The wordmark is EB Garamond 400 with negative tracking (-1.7px at 58px, -1.8px at 60px), matching the display scale. The SVGs carry **live text**, so EB Garamond must be loaded on the page or it falls back to Cormorant Garamond, then Georgia. Before handing these to a printer or an external party, convert the text to outlines so it can't reflow.

## Rules

- Clear space on all sides equals the height of the base stone.
- Minimum sizes: full lockup 120px wide, mark alone 24px. Below 24px use the favicon.
- Stroke weight scales with the mark. It's set at 4 units in a 100-unit box (≈2px at 50px) and thickened in the favicon so the stones stay open at 16px.
- The ember dot is the summit marker and stays orange. It's the only ember in the identity — don't reuse it decoratively elsewhere.
- Don't recolour the stones, restack them, change the offsets, or set the wordmark in Figtree.
